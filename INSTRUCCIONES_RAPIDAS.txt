  3. Se abrirá en tu navegador predeterminado

OPCIÓN 2 - Usar servidor local (recomendado):
  1. Abre terminal
  2. Escribe: cd /home/ubuntu/proyecto-educativo/
  3. Luego: python3 -m http.server 8000
  4. Abre navegador: http://localhost:8000
  5. ¡Presiona Ctrl+C para detener el servidor!

🎓 CÓMO USAR EN CLASE
═══════════════════════════════════════════════════════════════════════════════
1. MOSTRAR LA ESTRUCTURA HTML
   - Abre index.html en Sublime
   - Explica las etiquetas: <header>, <nav>, <main>, <footer>
   - Muestra cómo se organizan los menús

2. EXPLICAR EL CSS EXTERNO
   - Abre css/estilos.css
   - Muestra la conexión: <link rel="stylesheet" href="css/estilos.css">
   - Explica cómo se usan las clases CSS

3. DEMOSTRAR EN EL NAVEGADOR
   - Abre index.html en el navegador
   - Navega por las diferentes secciones
   - Muestra cómo funcionan los menús desplegables
   - Explica el diseño responsive

4. ANALIZAR COMPONENTES
   - Tarjetas (.tarjeta)
   - Cajas (.caja-destacada, .caja-info)
   - Botones (.boton)
   - Tablas
   - Líneas de tiempo

5. CREAR VARIACIONES
   - Pide a los estudiantes que cambien colores
   - Que agreguen nuevas páginas
   - Que modifiquen el contenido
   - Que personalicen el diseño

🎨 PERSONALIZACIÓN RÁPIDA
═══════════════════════════════════════════════════════════════════════════════
Para cambiar colores, edita css/estilos.css:

:root {
    --color-primario: #2c3e50;          ← Color principal (azul oscuro)
    --color-secundario: #e74c3c;        ← Color secundario (rojo)
    --color-acento: #3498db;            ← Color de acento (azul)
    --color-exito: #27ae60;             ← Color de éxito (verde)
    --color-advertencia: #f39c12;       ← Color de advertencia (naranja)
    --color-fondo: #ecf0f1;             ← Color de fondo
    --color-texto: #2c3e50;             ← Color de texto
}
